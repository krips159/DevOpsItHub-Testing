# Отчёт о дефекте

## Название
Conjured Mana Cake теряет меньше качества, чем предусмотрено требованием.

## Предусловия
Используется зафиксированная версия Gilded Rose из задания.

## Входные данные
`Item("Conjured Mana Cake", 5, 10)`

## Шаги воспроизведения
1. Создать товар с указанными значениями.
2. Передать его в `GildedRose`.
3. Вызвать `update_quality()` один раз.
4. Проверить поля `sell_in` и `quality`.

## Ожидаемый результат
`sell_in = 4`, `quality = 8`.

## Фактический результат
Заполнить точными значениями, полученными при запуске теста.

## Основание
Правило задания для Conjured: качество уменьшается в два раза быстрее, чем у обычного товара.

Источник требований: [Gilded Rose — репозиторий задания](https://github.com/emilybache/GildedRose-Refactoring-Kata).

## Статус
Заполнить после проверки фактического результата и подтверждения, что ожидание соответствует требованию.
