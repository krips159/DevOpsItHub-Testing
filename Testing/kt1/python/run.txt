# Результаты запуска тестов

## Команда
`.\.venv\Scripts\python.exe -m pytest -q tests/test_student_design.py`

## Версии
Python: указать вывод `--version`.
Pytest: указать вывод `--version`.

## Результат
Указать количество пройденных и упавших тестов.

## Анализ
Для каждого упавшего теста указать:
- имя теста;
- ожидаемое значение;
- фактическое значение;
- причину расхождения;
- вывод: ошибка теста, неоднозначность требования или дефект программы.
